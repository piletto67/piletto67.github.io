Privacy Policy

This application is a personal tool used only by its owner to access the owner's own Google Drive through rclone.

Data collection

The application does not collect, store, sell, or share any data from any user other than its owner. It has no servers and no database. Authorization tokens are stored only on the owner's own devices.

Use of Google user data

The application requests access to Google Drive solely so that the owner can list, upload, download, and manage their own files with rclone. Google user data is never transferred to third parties, used for advertising, or used for any purpose other than the owner's own file management.

Changes

If this policy changes, the updated version will be posted on this page.
